📖 レポート作成サイトの使い方完全ガイド

📌 はじめに（最初に設定すること）
画面左上の「👤生徒情報」に【学年・組・番号・氏名】を入力してください。入力が完了すると、自動的にすべてのツールが使えるようになり、紙の右上にお名前が印字されます。

1. パーツの追加と配置

  • パーツの狙い撃ち配置：パーツ追加ボタンや画像読み込みを行うと、マウスポインターに「📍 ここに追加」バッジが追従します。紙の好きな場所をクリック・タップするとその場所に配置されます！
  • 画像を選ぶ・貼る：Chromebookやパソコン内の画像を追加する場合は「📁 画像を選択」を押します。ウェブ上の画像をコピーした場合は「📋 画像貼付け」またはキーボードの [ Ctrl ] + [ V ] で直接貼ることができます。

2. 文字の編集・一部だけ大きくする・波線をつける

  • 文章の一部だけサイズ変更：文章中の【変更したい文字だけを指やマウスで選択（ハイライト）】した状態で、「スタイル＆書式」の【サイズ】の数字を変更すると、選択した文字だけを大きく/小さくできます！
  • 波線・二重線・下線・太字：文字を選択して「波線」「＝ 二重線」「下線」「B 太字」を押すと、選択箇所だけに装飾を付けられます。もう一度押すと消せます。
  • 文字色・フォント変更：角ゴシック・丸ゴシック・明朝体・毛筆風などに一括・部分変更できます。

3. 右クリックメニュー & キーボードショートカット

  • 右クリック操作：パーツや紙の上で右クリック（タッチパネル長押し）すると、コピー・切り取り・貼り付け・複製・前面/背面移動・削除の便利メニューが表示されます。
  • [ Ctrl ] + [ C ] / [ X ] / [ V ]：パーツのコピー・切り取り・貼り付けを行えます。
  • [ Ctrl ] + [ D ]：選択中のパーツを複製（重ねて増やす）します。
  • [ Ctrl ] + [ Z ] / [ Y ]：直前の操作を元に戻す・進める。
  • [ Delete ] キー：選択中のパーツを削除します（文字入力中を除く）。

4. 見本(B゜)PDFと復元機能

  • 📄 見本(B゜)PDF：プロレベルのレポート構成を画面上で確認し、そのままPDF出力やキャンバスへの復元が可能です。

5. 保存と提出（PDFの作り方）

  • 📄 PDF保存（提出用）：完成したら「📄 PDF保存」を押します。印刷画面が開くので、送信先を「PDFとして保存」にして保存してください。
  • 📁 その他：作業途中のデータをパソコンに保存したいときは「その他」メニューの「名前を付けて保存 (.hpb)」をご利用ください。次回「ファイルから読み込み」で続きから編集できます。

🖼️ 画像の貼り方手順

💡 おすすめ：「📁 画像ファイルを選択」ボタンでパソコンやChromebookにある画像を選ぶのが一番簡単・確実に貼り付けできます。

  1. Google画像検索などで画像をコピーした場合：
    画像上で右クリック（または長押し）して「画像をコピー」を選択。
    この画面に戻り、キーボードの [ Ctrl ] + [ V ] を押すか、「📋 画像貼付け」ボタンを押します。
  2. 画像ファイルをお持ちの場合：
    「📁 画像ファイルを選択」ボタンを押し、写真や画像を選ぶだけで紙の上に配置されます。
※画像はgoogle画像の規制の関係できちんと反映＆保存されない可能性があります。もし反映＆保存がされていなかった場合はもう一度貼り直しましょう。
